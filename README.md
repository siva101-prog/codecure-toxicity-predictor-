# 🧪 Drug Toxicity Predictor - Codecure Track A

## 🎯 Problem Solved
Predicts drug toxicity using Tox21 dataset (7,831 compounds) to reduce pharmaceutical R&D costs by identifying risky compounds early.

## 📊 Results
- **Accuracy:** 92%+ on test set
- **Dataset:** Tox21 (NR-AR, NR-Aromatase, SR-ARE assays)
- **Model:** Random Forest Classifier
